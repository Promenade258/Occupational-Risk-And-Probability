# Occupational-Risk-And-Probability

### 代码描述
这两个Python文件围绕**2030年AI对职业自动化影响**展开数据分析与预测建模，核心基于`AI_Impact_on_Jobs_2030.csv`数据集完成以下核心功能：

#### 1. 数据预处理
- 读取CSV数据并删除缺失值，并将英文列名翻译为中文，方便数据清晰展示；
- 筛选核心特征列（职业名称、薪资、工作年限、学历、AI互动程度等），对分类特征（学历、职业名称、风险分类）进行标签编码，适配模型训练。

#### 2. 可视化分析
- 生成多类图表：不同学历的薪资柱状图、工作年限与薪资的散点图（关联自动化概率）、特征相关性热力图、不同风险分类的多维度折线图、职业数量分布柱状图；
- 输出混淆矩阵热力图（评估分类模型效果），直观呈现数据规律与特征关联。

#### 3. 预测建模
- **回归预测（`聚类-职业预测自动化概率`）**：构建随机森林、决策树回归模型，预测职业2030年自动化概率；补充K-Means聚类，按薪资/AI互动程度等特征将职业分组；
- **分类预测（`分类-预测职业的自动化风险类别`）**：基于朴素贝叶斯、逻辑回归算法，预测职业的自动化风险分类；
- 提供交互式预测功能：支持用户输入职业名称/薪资/学历等信息，实时输出自动化概率/风险分类结果。

#### 4. 模型评估
- 回归模型：计算MSE、MAE、R²指标，输出特征重要性排序；
- 分类模型：评估准确率、输出分类报告与混淆矩阵，验证模型效果。
